# FocusFlow · 番茄专注

一个运行在 Edge / Chrome 里的番茄钟扩展：可以给每次专注打上用途标签（学习、工作、看视频……），
配合实时合成的沉浸氛围音，并把每次专注记录成可视化报告。

数据全部保存在本机浏览器里，不联网、不需要注册、不花钱。

---

## 一、安装到 Edge（约 2 分钟）

扩展已经写好了，你不需要编译、不需要装 Node，直接加载就能用。

1. 打开 Edge，在地址栏输入下面这行并回车：

   ```
   edge://extensions
   ```

2. 在页面**左下角**找到「开发人员模式」，把开关打开。

3. 页面顶部会出现几个新按钮，点击「**加载解压缩的扩展**」。

4. 在弹出的选择框里，定位到下面这个文件夹并选中它（选文件夹本身，不要进去选某个文件）：

   ```
   D:\Apractice\FocusFlow\pomodoro-edge
   ```

5. 列表里出现「FocusFlow · 番茄专注」就成功了。首次安装会自动打开报告页。

6. 点击 Edge 工具栏右侧的「扩展」图标（拼图形状），找到 FocusFlow，点旁边的**小图钉**把它固定到工具栏。

7. 之后点工具栏那个橙色圆环图标，就能打开番茄钟。

> 重新加载：改完代码后回到 `edge://extensions`，点 FocusFlow 卡片上的刷新图标即可。
> 卸载：卡片上的「删除」。注意卸载会连带清掉本地记录。

## 二、怎么用

### 日常计时

1. 点扩展图标，弹出小窗。
2. 在顶部选一个用途（学习 / 工作 / 看视频 / 娱乐 / 阅读）。
3. 点「开始专注」。默认 25 分钟，倒计时圆环会开始收缩。
4. 想安静下就点音乐条左边的播放键，展开菜单选一个音色（见下表）。
5. 时间到会自动提醒、记一笔记录，并切换到 5 分钟短休息。

**关掉小窗不会中断计时**。图标上会显示剩余分钟数，鼠标悬停可看状态。暂停时图标显示 `II`。

### 音色一览

菜单里分两组，共 8 种，全部是实时合成，没有音频文件：

| 分组 | 音色 | 特点 |
| --- | --- | --- |
| 氛围 | 雨声 | 带缓慢起伏的雨势，中高频为主 |
| 氛围 | 篝火 | 低频燃烧声 + 随机爆裂声 |
| 氛围 | 溪流 | 流动感，中高频带宽较宽 |
| 氛围 | 深空 | 极低频铺底 + 稀疏高频，空间感 |
| 噪音 | 白噪音 | 全频段能量均等，最标准的「沙沙」声，遮环境噪音最强 |
| 噪音 | 粉红噪音 | 每倍频程 −3 dB，低频更厚，接近下雨/瀑布，久听不累 |
| 噪音 | 紫噪音 | 每倍频程 +6 dB，明亮偏「嘶」，适合盖住说话声 |
| 噪音 | 灰噪音 | 白噪音按等响曲线反向补偿，各频段听感一样响，比白噪音耐听 |

四种噪声的响度做过归一化，切换时不会忽然变大变小。

### 计时按钮

| 按钮 | 作用 |
| --- | --- |
| 开始 / 暂停 / 继续 | 主按钮，随状态变化 |
| 重置 | 回到本轮开头，不记录 |
| 跳过 | 直接切到下一阶段，不记录 |

### 看报告

点弹窗底部「查看报告」，或右上角「报告」，会打开一个完整页面：

- **今日 / 本周 / 本月 / 全部** 四个时间范围
- 总专注时长、日均、连续打卡天数、今日目标达成率
- 用途分布环形图（哪种活动占了多少）
- 每日趋势柱状图（哪天专注得多）
- 各用途明细与最近 8 条记录
- 右下「导出 CSV」，可用 Excel 打开

### 改设置

报告页顶部切到「设置」标签：

- 专注 / 短休息 / 长休息时长、几个番茄后进长休息
- 每日目标分钟数
- 自动开始下一阶段、提示音、桌面通知、自动播氛围音
- 新增 / 改名 / 换色 / 删除用途（最多 10 个）
- 导出全部记录、清空记录

## 三、数据存在哪

存在 `chrome.storage.local`，也就是这个扩展自己的本地存储区，**不在你的个人文件里，也不上传**。

- 卸载扩展 = 数据一起删除，卸载前请先「导出 CSV」。
- 换电脑不会自动同步（当前版本没做云端同步）。
- 一个专注段不足 60 秒不会被记录，避免误触产生脏数据。

## 四、常见问题

**Q：关掉浏览器还在计时吗？**
不在。扩展依赖浏览器进程，Edge 完全退出后计时会停；下次打开 Edge 时如果结束时间已过，会自动把这一轮结算掉。

**Q：为什么点了播放没声音？**
浏览器禁止页面在没有用户操作时自动播放音频。手动点一次播放键即可，之后会保持。另外检查音量滑杆是否拉到 0。

**Q：音乐会不会因为关掉小窗就停？**
不会。音频跑在独立的「离屏文档」里，和弹窗生命周期无关，只有关浏览器才会停。

**Q：为什么关掉小窗后图标上的时间不是逐分钟跳？**
后台每分钟刷新一次角标，这是浏览器的省电机制；弹窗打开时是逐秒精确的。

**Q：数据会不会丢？**
只要不卸载扩展、不清浏览器数据就不会。建议每月导出一次 CSV 备份。

## 五、文件结构（想改代码时看）

```
pomodoro-edge/
├── manifest.json        扩展的身份证：声明权限、入口、图标
├── background.js        后台服务：计时状态机、闹钟、角标、通知
├── popup.html/.js       点图标弹出的小窗
├── dashboard.html/.js   报告页 + 设置页
├── offscreen.html/.js   音频引擎（Web Audio 实时合成，无音频文件）
├── lib/core.js          共享逻辑：数据模型、存储、时间与统计计算
├── styles/              三份样式表（基础变量 / 弹窗 / 报告页）
├── icons/               图标 16/32/48/128
```

> ⚠️ **加载扩展时选的就是这个 `pomodoro-edge` 文件夹**。它里面不能再放任何以下划线开头的文件或文件夹（如 `_tools`）——Chrome/Edge 规定 `_` 开头的名字是系统保留的，会直接报「无法加载扩展」。所以开发辅助脚本都放在同级的 `pomodoro-edge-dev` 目录里，与扩展完全分离。

几个技术要点，方便你以后自己改：

- **计时为什么不放在弹窗里**：弹窗关闭后它的页面就销毁了，计时必须放在 `background.js`（Service Worker）里，用 `chrome.alarms` 定时唤醒。
- **状态怎么算**：不存「剩余秒数倒着减」，而是存「结束时间戳」，剩余 = 结束时间 − 现在。这样即使后台被休眠、电脑睡眠，时间也不会算错。
- **声音怎么来的**：没有 mp3，全是 Web Audio 实时合成的白/棕/粉/紫噪音加滤波器与振荡器。所以扩展只有几百 KB，也没有任何版权问题。
- **图表怎么画的**：全部手写 SVG，不引 Chart.js 之类的库——扩展的 CSP 不允许加载远程脚本。

开发辅助脚本（都在**同级目录 `pomodoro-edge-dev`** 里，要先 `cd` 进去）：

```bash
cd ../pomodoro-edge-dev
node test-core.mjs      # 统计与时间计算测试（24 项）
node test-flow.mjs      # 计时状态机测试（15 项）
node test-noise.mjs     # 噪音频谱/响度/预设一致性测试（56 项）
node gen-icons.js       # 重新生成图标
node preview-server.js  # 在普通网页里预览界面（http://127.0.0.1:8787/popup.html）
```

## 六、还可以继续做

按你之前的选择，这些是二期可加的：

1. **专注时屏蔽分心网站**（扩展独有能力，需要 `declarativeNetRequest` 权限）
2. 番茄周期自定义（休息也可选用途）
3. 数据云同步（需要后端，或接 Edge 账号的 `storage.sync`，但容量只有 100KB）
4. 小组件 / 侧边栏常驻版本
5. 更细的报告：按小时的专注热力图、月历视图、周对比
